The big picture

Fighting AI with AI

Microsoft's message at Ignite: AI has shrunk the time from discovering a vulnerability to exploiting it from months to minutes, so defense has to run at machine speed too. The security announcements were grouped around three goals.

01

Secure your foundations

Close the gaps attackers go after first: shield unpatched systems, prioritize exposure, harden defaults with Baseline Security Mode, and protect data before AI reaches it.

02

Defend with agents

Microsoft Perception puts teams of red, blue and green AI agents to work on triage, investigation, detection and remediation. People approve the high-impact actions.

03

Secure agentic insiders

Discover every agent, give it an identity, contain what it can do, protect the data in its path and keep scoring its risk.

“
Agents are the new insiders.
Aleš Holeček, President and Chief Architect, Microsoft Security, on the Microsoft Security Blog

Agentic security

Microsoft Perception

Microsoft's agentic security system is now generally available. Teams of specialized red, blue and green AI agents work through playbooks to test, defend and fix, while your team sets the guardrails and approves high-impact actions.

Microsoft Security Blog Perception deep dive
7 updates
GA

Microsoft Perception is generally available

Formerly Project Perception. It coordinates red (attack simulation), blue (detection and investigation) and green (remediation) agent teams in a closed loop, with automated triggers, approval controls, audit logging, usage dashboards and a cost estimator.

GA

Blue team agents for the SOC

Alert Triage, Attack Investigation, Detection Authoring and Threat Intelligence agents. Triage can now handle about 80% of the alerts in a typical Defender queue; investigation follows an attack across endpoints, identities, email, Active Directory and cloud.

Recon Agent GAWeb App Pen Test preview

Red team agents find weaknesses first

The Recon Agent looks at your estate the way an attacker would. The new Web App Pen Test Agent proves which flaws are exploitable, and the Protect web app playbook carries the fix through to your code in GitHub.

Posture Prioritization GARisk Reduction preview

Green team agents reduce exposure

Prioritize the exposures that matter using threat intelligence and business context across Microsoft, AWS and Google Cloud. The Risk Reduction Agent coordinates patching through Intune, or recommends shielding when no patch is ready yet.

Preview

Beyond the Microsoft stack

Agents can now reason over AWS, Okta and Salesforce signals. Playbooks launch from Defender or fire automatically, and MCP plus APIs connect Perception to your SIEM, SOAR and ITSM tools.

New

New detection and threat playbooks

A detect emerging threats playbook turns threat research into tenant-aware KQL detections tested against your historical data. From any threat analytics article, Protect against a threat checks your coverage and adds custom detections.

Private preview

Playbooks to secure AI agents

Perception and Microsoft 365 share signals and agent registry data to investigate AI posture risks and unusual agent behavior, then drive prioritized remediation.

Microsoft Defender + Microsoft Sentinel

Security operations

SIEM and XDR are merging into one Integrated Security Operations Center (ISOC) inside the Defender portal. It's the shared data foundation that people and agents use to run an agentic SOC.

Defender & Sentinel post Sentinel post
7 updates
Core GA

Integrated SOC (ISOC) in Microsoft Defender

Case management, playbooks, workbooks, UEBA, workspace creation and third-party data ingestion are generally available. SIEM and threat protection now work in one experience.

Preview

Full SIEM and 90 days of Defender data included

Eligible Defender Suite, Microsoft 365 E5 and E7 customers get the full breadth of Sentinel SIEM capabilities, 90-day default retention for Defender data (up from 30), 500+ connectors, reduced ingestion rates and a built-in data lake.

Opt-in from Nov 17

Sentinel customers can opt in to ISOC

Existing Sentinel customers with Microsoft 365 E5, E7 or Defender Suite can move into ISOC, with ingestion at $2.4 per GB. Opting in is optional, so you can keep running Sentinel as you do today.

Public preview Dec 2026

Ingest-time data normalization

Microsoft-managed parsers standardize selected logs as they arrive. Queries get simpler and faster, and the same data can be reused for detection, hunting, investigation and agents.

Preview

New SOC tooling

SOC optimization recommendations, Content Hub and detections as code arrive in Defender, along with audit logs that show who created, changed, turned on or deleted automation rules and generated playbooks.

New

500+ connectors and richer context

New sources include Edge for Business, Purview Information Protection, Dragon Copilot, CrowdStrike, Wiz, Salesforce and OpenAI audit logs. CrowdStrike detections can become Defender alerts, AWS and Okta signals extend attack disruption, and UEBA adds AWS GuardDuty, Check Point, Zscaler and Fortinet.

Builder Agent GA end of NovHealth view preview

Build and monitor connectors faster

The Sentinel Connector Builder Agent in VS Code uses AI to generate, validate and deploy connectors. A new Data & Connectors overview in Defender shows connector health, ingestion volume and latency in one place.

Microsoft Defender

Threat protection

These protections aim to close the window between disclosure and patch, and to stop attacks where people actually work: the browser, Teams and the endpoint.

Endpoint security post Threat intelligence post
9 updates
Preview

Vulnerability shielding

It's on by default. AI picks the narrowest temporary control that protects an exposed, unpatched system, and applies it on its own during an active attack. That buys time until the permanent patch is deployed.

Rolling out by year end

ClickFix attacks blocked at the clipboard

A new clipboard monitor catches malicious commands copied from fake CAPTCHAs and error pages before they reach the Run dialog, terminal or Explorer, then clears them. ClickFix made up 12.8% of the intrusions Defender observed over the past year.

Public preview

QR-code phishing protection in Teams

Defender finds malicious URLs hidden in QR codes shared in Teams chats, blurs the harmful content and shows warning banners. It needs no extra admin setup, and analysts can hunt across it in advanced hunting.

Via certified partners

Deepfake detection in Teams meetings

Detection of synthetic audio and video from certified third-party providers flags possible deepfakes in meetings. The detections appear in Defender alongside your other security signals.

Preview

Zero-day and emerging-threat intelligence

A revamped threat intelligence experience labels zero-day and emerging threats and adds a zero-day widget, industry and region filters, and email alerts. A one-click Perception playbook then checks your coverage.

Preview in coming weeks

Endpoint health dashboard

One view shows deployment, cloud connectivity, antivirus status and update currency across your endpoint estate. You can drill into affected devices and open remediation guidance.

New

Safer change and device lifecycle

Staged deployment channels for Defender platform and engine updates on Windows and Linux, opt-in by feature for previews, traceable time-limited offboarding packages, and protection for shared Android and iOS frontline devices.

Public preview Dec 9

More custom data collection

Collect Linux file events (created, deleted, renamed) and Windows registry events straight from the Defender portal, with no extra collection agent.

New

Stopping attacks on the identities behind agents

New detections catch identity attacks aimed at agents, such as device-code phishing of a developer's GitHub account to misuse GitHub Copilot CLI. Defender can automatically disable the account and revoke its sessions.

Securing AI agents

Microsoft's plan here: discover every agent, give each one an identity, contain what it can do, protect the data in its path and keep reassessing its risk as it changes.

Agent 365 post Book of News: Security
10 updates
Defender discovery GANetwork & shadow AI preview

Find every agent, including shadow AI

Discovery adds 35 local agent types for 60 in total, including Claude Code, OpenAI Codex and GitHub Copilot, plus third-party cloud agents on AWS and Google Cloud. Everything lands in the Agent 365 registry.

Preview

Dynamic Agent Risk

Each agent gets one continuously updated risk level that combines identity, access, data, endpoint, cloud and network signals with exposure and blast radius. It appears in the Microsoft 365 admin center, Defender, Entra and Purview, and includes partner signals from Check Point, Cyera, Darktrace and Zenity.

GA on Windows

Runtime protection for local AI agents

Defender inspects the agent loop and can block hidden malicious instructions before the agent acts. Coverage includes Claude Code, GitHub Copilot CLI and app, VS Code extensions, OpenClaw, Ollama and ChatGPT. Choose Audit or Block mode in Defender or Intune (Defender for Endpoint P2).

Preview

Posture for third-party agent platforms

Agents built on Amazon Bedrock, Google Gemini, Google Vertex AI and Anthropic Claude now appear in the same inventory as Copilot Studio and Foundry agents, with risk assessments and recommendations.

Preview, rolling out through Dec

Entra Agent ID for connected platforms

Agents from Salesforce Agentforce, Amazon AgentCore, Google Vertex AI, Databricks, Snowflake, Anthropic, OpenAI, SAP, ServiceNow, UiPath and others get their own Entra identity. A guided connection wizard and secretless authentication make setup easier.

Preview

Contain local agents on the device

Intune compliance policies flag devices that run unsanctioned agents so Conditional Access can block them. For approved agents, Microsoft Execution Containers (MXC) enforce file and network boundaries that the agent can't change.

Preview

Windows process containers for agents

New container controls set limits for each agent on COM and IPC communication, network reach and identity proofing. A learning mode lets you watch normal behavior before you enforce.

Plugin & skill governance GAMCP governance previewAction center Dec

Agent 365 governance upgrades

Control centrally which people can use which plugins and skills in Copilot and Cowork, govern MCP servers from Azure AI Gateway and LiteLLM, and use a new action center to clean up inactive and ownerless agents.

Preview

Managed agent browsing in Edge for Business

IT can require agents to use Edge for Business for browser tasks. Each agent gets its own clearly marked window and Entra agent identity, and stays within the user's permissions.

Public preview

Multi-tenant agent management

Partners and enterprises manage agents across all their tenants from one place, deciding which agents run where and who can use them.

Microsoft Entra

Identity & network access

Entra's goal for this release is secure access for every identity, human or agent, to any resource from anywhere. That covers stronger credentials, less standing access and new controls for agents.

Microsoft Entra post
10 updates
Passkeys default nowHigh assurance preview

Phishing-resistant from day one

Passkeys are now the default for new Entra accounts. High assurance credentials add identity verification from partners such as AU10TIX, IDEMIA, CLEAR and Entrust at onboarding, before sensitive access and at account recovery.

Preview

Conditional Access policy plans

You define access intent once and it's enforced consistently across every identity. Templates, including ones for AI agents, help remove gaps and conflicts between policies.

PreviewWindows 365 for Agents GA

Conditional Access for agents

Write separate policies for local agents that act for a user, so you can block a risky agent while the employee keeps working. You can also restrict sensitive actions during risky sessions and extend Conditional Access to the Cloud PCs that agents use.

Lifecycle policies GANew Agent IDs preview

Agent identity lifecycle

Discovered local agents (starting with GitHub Copilot CLI and Claude Code) get Agent IDs automatically, and Autopilot digital teammates get their own agent account and ID. Lifecycle policies check sponsors and activity, and agents inactive for 60 days are disabled by default.

Preview

Least privilege for people and agents

PIM brings just-in-time access to more resources and to AI agents. It adds VM connections from My Access with session recording, AI recommendations for least-privilege roles, a PIM-only mode and bulk clean-up. Dynamic permissions fix agents that have too much access.

Agent controls previewNetwork DLP GA

Global Secure Access for the agentic era

Get visibility into agent traffic, set network policies by agent type and use an MCP firewall for servers, tools and prompts. Purview DLP at the network layer, including for unsanctioned AI apps, is now generally available.

Preview

Govern every tenant, recover fast

Cross-tenant configuration management with drift detection, multitenant management for Agent 365 and Copilot, Backup and Recovery Premium with 30-day retention, and hard-deletion protection for critical objects such as Agent IDs.

GADynamic groups preview

Governance and admin automation

Guest lifecycle policies clean up inactive guest accounts automatically, and the Microsoft MCP Server for IT Admins lets AI tools query Entra, Purview and Intune data with permissions. New dynamic group rules follow existing memberships and reporting lines.

Preview

Customer identity with External ID

Brand sign-in pages with your own HTML templates or bring your own authentication UX. Also new: multiple first-factor sign-in, Native Auth API v2, an AI agent toolkit, self-service passkey APIs and TOTP for external users.

Preview

Secure BYOD access through Edge

Global Secure Access in Edge for Business lets employees reach private web apps from their work profile, even on personal devices, without a VPN client.

Microsoft Purview

Data security

Purview wants to get you to protection faster and cover every way sensitive data reaches AI: typed prompts, attachments, grounding data and agent tool calls.

Microsoft Purview post
6 updates
Public preview Jan 2027

Grounding protection for Copilot

DLP can stop Copilot from using files that contain sensitive information even when they aren't labeled, so you can roll out Copilot without labeling every file first.

Public preview Jan 2027

DLP for prompt attachments and links

Protection now covers files attached to or linked in Copilot prompts, not just typed text.

Public preview Jan 2027

DLP for local AI agents

See what local agents are doing and stop them from processing sensitive data that comes from prompts, files or tools. Policies can target a single agent or a group of agents.

From Jan 2027Unified management preview

Classification that keeps up

Improved built-in sensitive information types start with the 100+ most used ones. A recurring refresh reclassifies old content when classifiers improve, and every classifier type is now managed in one place.

GALibrary labels preview

Auto-labeling at scale

Label up to 500,000 SharePoint and OneDrive files a day (up from 100,000), simulate up to 20 million matches (up from 4 million) and target sites by attribute. Default library labels can now cover data at rest.

Public preview

Purview signals in agent risk

Agent activity and interactions with sensitive data feed the agent risk score in Agent 365, so security teams can spot and prioritize risky agents.

Windows + Microsoft Intune

Devices & Windows

Windows is getting stronger by default and becoming a governed place to run AI agents. Intune now links vulnerability findings to automated fixes.

Windows security post Intune post
7 updates
GA

Windows endpoint security platform

Security vendors can move critical protection out of the kernel into user mode, which makes Windows more resilient without losing protection. Partners include Bitdefender, CrowdStrike, ESET, SentinelOne, Sophos, Trellix and TrendAI.

GA

Windows administrator protection

Local admins run with standard rights by default. Windows Hello verifies the user and grants admin rights for a single task, and those rights end when the task does.

Preview (Insider)

Windows baseline protection

Secure boot, virtualization-based security and memory integrity combine into one versioned security state. You can verify it with hardware-backed attestation and get a clear yes or no for every device.

New

Post-quantum and passwordless

The Windows TLS stack adds more post-quantum key exchange and authentication. Windows Hello sign-in gets faster, with new sign-in insights for IT, broader web sign-in and easier security keys.

Limited public preview

Intune Vulnerability Remediation Agent

It combines Defender vulnerability intelligence with Intune device and app context to build and run automated app and OS patching plans. Run it from the Intune admin center or through Perception.

Insider preview

Windows Server in Intune and Autopatch

Eligible servers, including edge and branch servers, join the same cloud management, compliance and update workflows as Windows clients.

App inventory previewAuto-updates private preview

Keep apps current and governed

Device-level app inventory, automatic updates for more verified Windows apps and app-in-use detection all help keep software current. Leading AI apps such as Copilot, GitHub Copilot, Claude and ChatGPT support Intune app protection.

Secure by default

Secure-by-default foundations

Attackers can now turn a flaw into an exploit within hours, so Microsoft is pushing safer defaults and hygiene programs you can measure.

Baseline security mode post On-premises initiative
4 updates
GA, phased rollout

Baseline Security Mode 2026

Microsoft's recommended secure defaults now cover Intune, Purview and Dynamics 365, with Azure and Windows in private preview. It adds a new Applications category and 24 new settings, such as MFA for guests and blocking native COM add-ins. You can simulate each setting first.

Preview Jan 2027

AI Readiness Initiatives

Measurable plans in Perception that follow Secure Now guidance. The first ones cover patching and vulnerability management, phishing-resistant admin sign-in, and agent discovery and governance. Progress is tracked with live tenant data.

Rolling out over time

On-premises security initiative

Guidance, migration support and a future On-Premises Baseline Security Mode for Exchange Server, SharePoint Server and Skype for Business Server. The aim is faster updates, safer defaults and temporary protection against new threats.

Announced

AI Transparency Initiative

Microsoft commits to helping organizations see what their AI accesses and does, verify it independently and control it, whatever the model. It's expanding its work with NIST on agent standards and shaping the approach with more than 40 organizations, including Accenture, Adobe, KPMG, Mastercard and Volvo Cars.

Put it to work

Five practical next steps

Practical ways to act on the announcements now.

  1. Simulate Baseline Security Mode

    In the Microsoft 365 admin center, go to Org Settings, then Security & Privacy, then Baseline security mode. Run the new settings in simulation before you enforce them.

  2. Plan your ISOC and Defender portal move

    Check eligibility (Defender Suite, Microsoft 365 E5 or E7) for included SIEM and 90-day retention. Move Sentinel to the Defender portal before Mar 31, 2027.

  3. Inventory your agents

    Use Agent 365 to bring local, shadow and third-party agents into one registry. Start Defender runtime protection in Audit mode, then switch to Block.

  4. Get Copilot data protection ready

    Review your DLP policies and sensitive information types now, so the January 2027 grounding and prompt protections are ready to switch on.

  5. Pilot Perception playbooks

    Start with triage and investigation playbooks, set your approval guardrails, and use the cost estimator to plan usage.
